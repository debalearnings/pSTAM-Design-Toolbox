# Target: Python 3.10 or 3.11 inside a dedicated virtual environment.
#
# This file does NOT install the GUI toolkit (PyQt5), because PyQt5 is
# installed differently on different machines:
#   - Windows and x86-64 Linux:  pip install -r requirements-desktop.txt
#                                (this file plus PyQt5 from PyPI)
#   - ARM64 Linux, e.g. NVIDIA Jetson:  PyQt5 from the system package
#     manager (apt install python3-pyqt5), then this file only.
#     PyPI publishes no ARM64 Linux wheel for PyQt5.
# See SETUP_AND_RUN.txt for the exact commands.
#
# NumPy is pinned below 2.0 on purpose: the versions below form one
# coherent NumPy 1.x stack that installs from prebuilt wheels on
# Windows, x86-64 Linux and ARM64 Linux.
# ---------------------------------------------------------------------
